# Homebrew Tap for Aria2 Next

[Aria2 Next](https://github.com/AnInsomniacy/aria2-next) is a download engine with aria2's command line and JSON-RPC, rebuilt on mature libraries.

```bash
brew install aninsomniacy/aria2-next/aria2-next
```

The formula installs the release binaries for macOS (Apple Silicon and Intel) and Linux (x86_64 and ARM64), each pinned to the SHA-256 published with the release. Linux binaries require glibc 2.35 or newer.

`Formula/aria2-next.rb` is generated by the Aria2 Next release workflow for every release; report problems in the [Aria2 Next repository](https://github.com/AnInsomniacy/aria2-next/issues).
